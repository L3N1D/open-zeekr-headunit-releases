# Open Zeekr Headunit — releases

Builds of Open Zeekr Headunit, a fork of [Open Headunit](https://github.com/andreknieriem/open-headunit) tuned for the Zeekr X head unit (Android Auto on the screen, its cluster map on the HUD).

The app checks this repository's releases itself and offers to install a newer one, while Android Auto is not connected. Each release has one APK, `open-zeekr-headunit.apk`.

Not affiliated with or endorsed by Zeekr.
