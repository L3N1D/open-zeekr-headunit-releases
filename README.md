# Open Zeekr Headunit

**Android Auto для магнитолы Zeekr X — на полном экране и в карточке карты штатного рабочего стола.**

Проект основан на [Open Headunit](https://github.com/andreknieriem/open-headunit) и адаптирован для интеграции с интерфейсом автомобиля. В этом репозитории находятся исходники и [готовые выпуски APK](https://github.com/L3N1D/open-zeekr-headunit-releases/releases).

## Возможности

- Проводное USB и беспроводное подключение Android Auto, включая Native Mode.
- Отображение AA в карточке карты с изменением размера при скрытии и выдвигании боковых виджетов.
- Сохранение окна проекции при возврате из штатного списка приложений.
- Передача информации о треке в музыкальный виджет автомобиля.
- Интеграция с темой магнитолы и поддержка автомобильных команд управления мультимедиа.
- Настройки отображения, подключения и диагностики.

Пакет приложения: `com.lenid.zoh`. Название в списке приложений: **Open Zeekr Headunit**.

Автомобильные интеграции зависят от прошивки и предоставленных приложению разрешений. Проверки выполняются на Zeekr X; совместимость с другими моделями и прошивками не гарантируется.

## Установка

1. Откройте [Releases](https://github.com/L3N1D/open-zeekr-headunit-releases/releases) и прочитайте описание выбранного выпуска.
2. Скачайте приложенный APK и установите его на магнитолу доступным для вашей системы способом.
3. Откройте приложение, предоставьте необходимые разрешения и выберите способ подключения телефона.
4. Для размещения AA на рабочем столе включите карточку карты в настройках приложения, если прошивка поддерживает эту интеграцию.

Исходники в ветке `main` могут быть новее последнего выпуска APK. Ранее выпущенные APK могут иметь другое имя пакета: Android устанавливает их отдельно, а настройки автоматически не переносятся. Для обновления поверх установленной версии должны совпадать имя пакета и подпись.

## Сборка Open Zeekr Headunit

Необходимы JDK 21, Android SDK Platform 36, NDK `29.0.14206865` и CMake `3.22.1`.

Укажите путь к SDK через `ANDROID_HOME` или локальный `local.properties`, затем выполните:

```sh
./gradlew :app:assembleGithubDebug
./gradlew :app:testGithubDebugUnitTest
```

APK создаётся в `app/build/outputs/apk/github/debug/`.

Ключи подписи, локальные настройки, резервные копии и результаты сборок не входят в исходники. Без локального ключа платформы debug-сборка использует обычную отладочную подпись: привилегированные функции магнитолы могут быть недоступны, а установка поверх APK с другой подписью не сработает.

## Обновление 1.0.4

На главном экране появился общий список USB-устройств и сопряжённых телефонов с выбором устройства и кнопкой подключения. Сопряжение Bluetooth не гарантирует доступность телефона или поддержку проекции. Сохранены отдельные карточки подключения и их анимации.

Прямой CarPlay и CarPlay Ultra — экспериментальные функции. Успешное подключение реального iPhone/TBox и работа на магнитоле пока не подтверждены. Данные аутентификации CarPlay не включены в APK или исходники. Настройки диагностики находятся в разделе подключения.

CarPlay основан на DiPlay и [Tarmac](https://github.com/Altair571/tarmac). Based on LIVI by Lasse Heitgres (https://github.com/f-io/LIVI). Лицензии и уведомления: `carplay/UPSTREAM.txt`, `carplay/LICENSE`, `carplay/docs/licenses/LIVI-NOTICE.txt`.

### Отчёты об ошибках (Bugsink)

В официальной сборке 1.0.5 подключён Bugsink. Существующий `CrashJournal` отправляет
отчёты в фоновом потоке через совместимый с Sentry API, без дополнительного SDK.
Отправку можно отключить переключателем «Отправлять отчёты об ошибках».
Неотправленные отчёты остаются на устройстве и могут отправиться после повторного
включения этой настройки. Это не непрерывная передача всего журнала.

Отчёт содержит сведения об ошибке, версии приложения и устройства, а также
фрагмент журнала. Маскирование отдельных полей не гарантирует удаления всех
личных данных: не записывайте пароли и данные аутентификации в журнал.

Для самостоятельной сборки укажите `sentry.dsn` в исключённом из Git файле
`local.properties`. Пустой адрес оставляет отчёты только на устройстве.
Адрес встраивается при сборке APK; уже установленное приложение не получает
изменения этого файла автоматически.
